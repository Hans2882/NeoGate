# Monitoring Sistem

Halaman monitoring digunakan untuk melihat kondisi sistem secara real-time.

## Status Palang

Menampilkan kondisi palang saat ini.

| Status | Keterangan |
|---------|------------|
| TERBUKA | Palang terbuka |
| TERTUTUP | Palang tertutup |

## Status Kereta

Menampilkan kondisi jalur kereta.

| Status | Keterangan |
|---------|------------|
| AMAN | Tidak ada kereta |
| TERDETEKSI | Kereta terdeteksi |

## Status Sistem

Menampilkan kondisi sistem secara keseluruhan.

| Status | Keterangan |
|---------|------------|
| ONLINE | Sistem aktif |
| OFFLINE | Sistem tidak aktif |

## Pembaruan Data

Data diperbarui secara otomatis melalui Firebase tanpa perlu melakukan refresh halaman.
