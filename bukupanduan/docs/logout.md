# Logout

Logout digunakan untuk mengakhiri sesi pengguna.

## Langkah Logout

1. Klik tombol Logout pada bagian atas dashboard.
2. Sistem akan menghapus sesi login.
3. Pengguna diarahkan kembali ke halaman login.

## Tujuan Logout

- Mengamankan akun pengguna.
- Mencegah akses oleh pihak yang tidak berwenang.
- Mengakhiri sesi penggunaan sistem.
