# NeoGate

NeoGate adalah Website Monitoring Sistem Palang Pintu Kereta Api Berbasis IoT yang digunakan untuk memantau kondisi perlintasan kereta api secara real-time.

Sistem menghubungkan sensor, ESP32, Firebase, dan dashboard web sehingga operator dapat melakukan pemantauan dengan cepat dan akurat.

## Tujuan Sistem

- Monitoring kondisi palang secara real-time.
- Monitoring keberadaan kereta api.
- Menyimpan riwayat aktivitas sistem.
- Membantu operator dalam pengambilan keputusan.

## Fitur Utama

- Login pengguna.
- Monitoring status palang.
- Monitoring status kereta.
- Monitoring mode operasi.
- Pengendalian sistem.
- Riwayat aktivitas.
- Integrasi Firebase.
