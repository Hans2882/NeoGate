# Memulai

## Persyaratan

Sebelum menggunakan sistem, pastikan:

- Perangkat terhubung ke internet.
- Browser telah terpasang.
- Akun operator telah terdaftar.

## Mengakses Website

1. Buka browser.
2. Masukkan alamat website NeoGate.
3. Tekan Enter.

Setelah berhasil dibuka, halaman beranda akan ditampilkan.

## Menu Utama

Menu yang tersedia pada halaman utama:

- Beranda
- Tentang
- Fitur
- Arsitektur
- Teknologi
- Login Dashboard
