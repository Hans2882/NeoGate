# Troubleshooting

## Dashboard Tidak Menampilkan Data

### Penyebab

- Internet terputus.
- Firebase tidak terhubung.
- ESP32 offline.

### Solusi

- Periksa koneksi internet.
- Periksa Firebase.
- Restart perangkat ESP32.

---

## Login Gagal

### Penyebab

- Email salah.
- Password salah.

### Solusi

- Periksa kembali email.
- Periksa kembali password.

---

## Sensor Tidak Terbaca

### Penyebab

- Sensor rusak.
- Kabel terputus.
- ESP32 mati.

### Solusi

- Periksa sensor.
- Periksa kabel.
- Restart perangkat.

---

## Data Tidak Real-Time

### Penyebab

- Koneksi internet lambat.
- Firebase mengalami gangguan.

### Solusi

- Periksa koneksi internet.
- Periksa status Firebase.
