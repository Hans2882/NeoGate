# Login

Halaman login digunakan untuk mengakses dashboard monitoring.

## Langkah Login

1. Klik tombol Login Dashboard.
2. Masukkan email.
3. Masukkan password.
4. Klik Login.

## Form Login

| Field | Keterangan |
|---------|---------|
| Email | Email pengguna |
| Password | Kata sandi pengguna |

## Login Berhasil

Jika data benar, pengguna akan diarahkan ke Dashboard.

## Login Gagal

Jika data salah, sistem akan menampilkan pesan kesalahan.
