# Dashboard

Dashboard merupakan halaman utama setelah pengguna berhasil login.

## Informasi Pengguna

Pada bagian atas dashboard terdapat:

- Nama Operator
- Gate Aktif
- Tombol Logout

## Informasi Dashboard

Dashboard menampilkan:

- Status Palang
- Status Kereta
- Mode Sistem
- Statistik Log
- Aktivitas Terakhir

## Fungsi Dashboard

Dashboard digunakan untuk:

- Monitoring kondisi sistem.
- Melihat status perangkat.
- Mengakses fitur pengendalian.
